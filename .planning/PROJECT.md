# ERPH Digital

## Vision
A digital lesson planner (Rancangan Pengajaran Harian) for Malaysian teachers following DSKP (Dokumen Standard Kurikulum dan Pentaksiran) guidelines.

## Primary Goals
1. **Automated RPH Generation**: Seamless creation of daily lesson plans based on DSKP.
2. **Supabase Integration**: Robust data persistence for all user records.
3. **PDF Generation & Export**: Clean, printable PDF output for administrative review.
4. **Jawi Encoding**: Full support for Jawi characters in input and PDF generation.

## Success Criteria
- [ ] Users can successfully save new RPH data to the database.
- [ ] Users can view their existing records in a clear list.
- [ ] Users can download or print a correctly formatted RPH PDF.
- [ ] Jawi characters are rendered correctly in the UI and the generated PDF.

## Context & Constraints
- **Stack**: React, TypeScript, Vite, Supabase.
- **Priority**: UI/UX Focus - the experience should be intuitive for teachers.
- **Standards**: Must comply with DSKP Malaysian educational requirements.
